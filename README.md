# RO 🇷🇴
<sub>english description below</sub>

Un solver de rationamente logice de tip:<br>
`P1, P2, P3 ..., Pn ⊨ C`
<br>
Foloseste metoda arborilor logici<br>

Operatiile valide sunt:<br>

OR, scris `|`<br>
AND, scris `&`<br>
NOT, scris `!`<br>
Implicatia logica (`→`), scrisa `>`<br>

Se pot folosi si paranteze `()` pentru a stabili ordinea operatiilor. Altfel, toate operatiile au aceeasi prioritate.<br>

Este un proiect de jucarie, deci nu include controale user-friendly.

Pentru a schimba input-ul, editati numele fisierului din instructiunea `freopen()` de pe primul rand al functiei `main()`<br>
Pentru a folos input-ul de la tastatura, stergeti randul cu instructiunea `freopen()`, sau puneti-o intr-un comentariu<br>

Input-ul este scris in formatul:<br>
```
P1
P2
P3
...
Pn
=>
C
```
<br>

Vedeti input-urile sample pentru exemple concrete. Programul nu face nicio validare a input-ului, deci aveti grija la formatare!<br>

# EN 🇬🇧/🇺🇸

A logical reasoning solver for arguments of the form:<br>
`P1, P2, P3 ..., Pn ⊨ C`
<br>
Uses the logical tableau method<br>

The valid operations are:<br>

OR, written as `|`<br>
AND, written as `&`<br>
NOT, written as `!`<br>
Logical implication (`→`), written as `>`<br>

Parentheses `()` can also be used to establish the order of operations. Otherwise, all operations have the same precedence.<br>

This is a toy project, so it does not include user-friendly controls.

To change the input, edit the filename in the `freopen()` statement on the first line of the `main()` function<br>
To use keyboard input, delete the line containing the `freopen()` statement, or comment it out<br>

The input is written in the following format:<br>
```
P1
P2
P3
...
Pn
=>
C
```
<br>

See the sample inputs for concrete examples. The program does not perform any input validation, so be careful with the formatting!<br>
